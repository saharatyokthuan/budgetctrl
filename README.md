# 💰 BUDGET//CTRL+ — แอปจัดการการเงินส่วนตัว

เว็บแอปจัดการการเงินส่วนตัวแบบหลายหน้า ทำงานบนเบราว์เซอร์ รองรับ PWA/ออฟไลน์ เก็บข้อมูลในเครื่องผ่าน `localStorage`

🔗 **ใช้งานออนไลน์:** https://saharatyokthuan.github.io/budgetctrl/

---

## ✨ ฟีเจอร์หลัก

| หน้า | ความสามารถ |
|:---|:---|
| 🏠 **หน้าแรก (Dashboard)** | สรุปรายรับ/รายจ่าย/ยอดคงเหลือ, รายการล่าสุด, แจ้งเตือน |
| 💳 **รายการ (Transactions)** | ดูรายการทั้งหมด, ค้นหา, กรองตามเดือน |
| 📊 **งบประมาณ (Budget)** | ตั้งงบประมาณ ติดตามความคืบหน้าการใช้จ่าย |
| 🏦 **หนี้ (Debts)** | จัดการหนี้สิน, ยอดคงเหลือ, วันครบกำหนด |
| 🎯 **เป้าหมาย (Goals)** | ตั้งเป้าหมายการออม, ติดตามความคืบหน้า |
| 🔄 **รายการประจำ (Recurring)** | รายรับ/รายจ่ายประจำซ้ำทุกเดือน |
| ⚙️ **การตั้งค่า (Settings)** | สำรอง/กู้คืนข้อมูล, ตั้งค่าระบบ |

---

## 📁 โครงสร้างไฟล์

```
budgetctrl/
├── index.html              # หน้าแรก / Dashboard
├── dashboard.html          # หน้าสรุปภาพรวม
├── transactions.html       # หน้ารายการทั้งหมด
├── budget.html             # หน้างบประมาณ
├── debts.html              # หน้าหนี้สิน
├── goals.html              # หน้าเป้าหมายการออม
├── recurring.html          # หน้ารายการประจำ
├── settings.html           # หน้าตั้งค่า
├── css/style.css           # ไฟล์สไตล์
├── js/db.js                # ชั้นข้อมูล (localStorage)
├── js/nav.js               # การนำทางระหว่างหน้า
├── js/utils.js             # ฟังก์ชันช่วยเหลือ
├── manifest.json           # ไฟล์กำหนด PWA
├── sw.js                   # Service Worker สำหรับใช้งานออฟไลน์
└── README.md               # ไฟล์นี้
```

## 🚀 วิธีใช้งาน

### ออนไลน์
เปิด https://saharatyokthuan.github.io/budgetctrl/

### ในเครื่อง
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที — หรือรันผ่าน local server:

```bash
python3 -m http.server 8000
```
แล้วเปิด http://localhost:8000

---

## 💾 การเก็บข้อมูล

ข้อมูลทั้งหมดเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่มีการส่งขึ้นเซิร์ฟเวอร์ การล้างข้อมูลเบราว์เซอร์จะลบข้อมูลทั้งหมด แนะนำให้สำรองข้อมูลเป็นไฟล์ JSON เป็นประจำที่หน้าตั้งค่า

---

## 🛠️ เทคโนโลยีที่ใช้

- HTML5, CSS3, Vanilla JavaScript (ไม่มีเฟรมเวิร์ก, ไม่มี build step)
- PWA (manifest.json + sw.js สำหรับใช้งานออฟไลน์และติดตั้งบนมือถือ)
- localStorage สำหรับเก็บข้อมูลฝั่ง client
